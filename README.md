# Weeek MCP Server

[![PHP Version](https://img.shields.io/badge/php-%3E%3D8.0-blue.svg)](https://php.net/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Сервер Message Control Protocol (MCP) для интеграции с API Weeek — системой управления проектами и задачами. Предоставляет интеллектуальный интерфейс для работы с задачами, проектами, досками и тегами через Claude Desktop и другие MCP-совместимые клиенты.

## 🚀 Основные возможности

- **Управление задачами**: создание, обновление, завершение, удаление задач
- **Управление проектами**: получение списка проектов и их информации  
- **Работа с досками**: создание досок, управление колонками досок
- **Система тегов**: создание, обновление и привязка тегов к задачам
- **Кэширование**: быстрая работа за счет локального кэша данных
- **Учет времени**: добавление записей времени к задачам
- **Гибкая конфигурация**: настройка через переменные окружения и конфигурационный файл

## 📋 Требования

- PHP 8.0+
- Composer
- API токен Weeek

## 🛠 Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/streeboga/weeek-mcp.git
cd weeek-mcp
```

2. **Установите зависимости:**
```bash
composer install
```

3. **Настройте конфигурацию:**
```bash
cp config.json.example config.json
```

Отредактируйте `config.json`:
```json
{
    "auth": {
        "weeek_api_token": "ваш_токен_weeek_api"
    },
    "default_project_id": "id_проекта_по_умолчанию",
    "default_board_id": "id_доски_по_умолчанию",
    "default_user_id": "id_пользователя_по_умолчанию",
    "timezone": "Europe/Moscow"
}
```

4. **Альтернативная настройка через переменные окружения:**
```bash
export WEEEK_API_TOKEN="ваш_токен"
export WEEEK_PROJECT_ID="123456"
export WEEEK_BOARD_ID="789012"
export WEEEK_USER_ID="345678"
```

## 🏃‍♂️ Запуск

```bash
php server.php
```

## 🔧 Настройка Claude Desktop

1. Откройте настройки Claude Desktop
2. Добавьте новый MCP сервер:

```json
{
  "mcpServers": {
    "weeek": {
      "command": "php",
      "args": ["/path/to/your/weeek-mcp/server.php"]
    }
  }
}
```

## 📚 API Инструменты

### 📝 Управление задачами

#### `create_task`
Создает новую задачу в Weeek.

**Параметры:**
- `title` (string, обязательный) — Название задачи
- `description` (string, опционально) — Описание задачи  
- `project_id` (string, опционально) — ID проекта (по умолчанию из конфига)
- `board_id` (string, опционально) — ID доски
- `board_column_id` (string, опционально) — ID колонки доски
- `parent_id` (string, опционально) — ID родительской задачи

**Пример:**
```javascript
create_task({
    "title": "Разработать новую функцию",
    "description": "Подробное описание задачи",
    "project_id": "123456"
})
```

#### `get_tasks`
Получает список задач с возможностью фильтрации.

**Параметры:**
- `project_id` (string, опционально) — Фильтр по проекту
- `board_id` (string, опционально) — Фильтр по доске
- `board_column_id` (string, опционально) — Фильтр по колонке доски

#### `get_task`
Получает информацию о конкретной задаче.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи

#### `update_task`
Обновляет задачу.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи
- `title` (string, опционально) — Новое название
- `description` (string, опционально) — Новое описание

#### `complete_task`
Отмечает задачу как выполненную.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи

#### `uncomplete_task`
Снимает отметку выполнения с задачи.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи

#### `delete_task`
Удаляет задачу.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи

#### `update_task_board`
Перемещает задачу на другую доску.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи
- `board_id` (string, обязательный) — ID новой доски

#### `update_task_board_column`
Перемещает задачу в другую колонку доски.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи
- `board_column_id` (string, обязательный) — ID колонки
- `upper_task_id` (string, опционально) — ID задачи, над которой разместить

### 🏷 Управление тегами

#### `get_tags`
Получает список тегов.

#### `create_tag`
Создает новый тег.

**Параметры:**
- `title` (string, обязательный) — Название тега
- `color` (string, опционально) — Цвет тега

#### `update_tag`
Обновляет тег.

**Параметры:**
- `tag_id` (string, обязательный) — ID тега
- `title` (string, опционально) — Новое название
- `color` (string, опционально) — Новый цвет

#### `delete_tag`
Удаляет тег.

**Параметры:**
- `tag_id` (string, обязательный) — ID тега

#### `attach_tag_to_task`
Присоединяет тег к задаче.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи
- `tag_id` (string, обязательный) — ID тега

#### `create_task_with_tag`
Создает задачу с привязанным тегом.

**Параметры:**
- `title` (string, обязательный) — Название задачи
- `tag_id` (string, обязательный) — ID тега
- `description` (string, опционально) — Описание задачи
- `project_id` (string, опционально) — ID проекта
- `board_id` (string, опционально) — ID доски

### ⏰ Учет времени

#### `add_task_time_entry`
Добавляет запись учета времени к задаче.

**Параметры:**
- `task_id` (string, обязательный) — ID задачи
- `user_id` (string, обязательный) — ID пользователя
- `date` (string, обязательный) — Дата в формате YYYY-MM-DD
- `duration` (number, обязательный) — Продолжительность в минутах
- `comment` (string, опционально) — Комментарий
- `is_overtime` (boolean, опционально) — Сверхурочное время

## 🏗 Архитектура

### Основные компоненты

```
src/
├── WeeekMcp.php          # Основной MCP сервер
├── Server.php            # Альтернативная реализация сервера
├── Methods/
│   └── TaskManager/
│       ├── Tasks.php     # Управление задачами
│       └── Boards.php    # Управление досками
├── Utils/
│   ├── Cache.php         # Система кэширования
│   ├── CacheLoader.php   # Загрузчик данных в кэш
│   ├── MpcReader.php     # Чтение MCP сообщений
│   └── MpcWriter.php     # Запись MCP сообщений
└── Api/
    └── TasksApi.php      # API интерфейс для задач
```

### Система кэширования

Проект использует файловую систему кэширования для ускорения работы:

- `cache/projects.json` — Кэш проектов
- `cache/boards.json` — Кэш досок  
- `cache/board_columns.json` — Кэш колонок досок
- `cache/tasks.json` — Кэш задач
- `cache/tags.json` — Кэш тегов

Кэш автоматически обновляется при изменении данных и может быть принудительно обновлен специальными командами.

## 🐛 Устранение неполадок

### Частые проблемы

1. **Ошибка токена API**: Убедитесь, что токен указан правильно в `config.json` или переменной окружения `WEEEK_API_TOKEN`

2. **Проблемы с кэшем**: Очистите папку `cache/` и перезапустите сервер

3. **Ошибки MCP**: Проверьте логи в `server_log.txt`

### Включение отладки

Для включения подробного логирования установите переменную окружения:
```bash
export DEBUG=1
```
