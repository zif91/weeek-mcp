## 📋 Доступные инструменты

### Управление задачами
- `create_task` — Создание задач
- `get_tasks` — Получение списка задач
- `get_task` — Получение конкретной задачи
- `update_task` — Обновление задач
- `complete_task` / `uncomplete_task` — Управление статусом
- `delete_task` — Удаление задач

### Управление проектами
- `get_projects` — Получение списка проектов

### Управление досками
- `get_boards` — Получение списка досок
- `create_board` — Создание досок
- `update_board` — Обновление досок
- `delete_board` — Удаление досок
- `reload_boards_cache` — Обновление кэша

### Управление колонками
- `get_board_columns` — Получение колонок
- `create_board_column` — Создание колонок
- `update_board_column` — Обновление колонок
- `delete_board_column` — Удаление колонок

### Система тегов
- `get_tags` — Получение тегов
- `create_tag` — Создание тегов
- `update_tag` — Обновление тегов
- `delete_tag` — Удаление тегов
- `attach_tag_to_task` — Привязка тегов
- `create_task_with_tag` — Создание задач с тегами

### Учет времени
- `add_task_time_entry` — Добавление записей времени

## 💡 Практические примеры

### Создание простой задачи
```javascript
mcp_Weeek_MCP_create_task({
    "title": "Написать документацию"
})
```

### Создание задачи с полными параметрами
```javascript
mcp_Weeek_MCP_create_task({
    "title": "Разработать API",
    "description": "Создать REST API для мобильного приложения",
    "project_id": "123456",
    "board_id": "789012"
})
```

### Создание доски для спринта
```javascript
mcp_Weeek_MCP_create_board({
    "title": "Спринт №5",
    "project_id": "123456"
})
```

## 🆘 Получение помощи

### Часто задаваемые вопросы

**Q: Как получить API токен Weeek?**
A: Войдите в аккаунт Weeek → Настройки → API токены → Создать новый

**Q: Сервер не запускается, что делать?**
A: Проверьте логи в `server_log.txt` и убедитесь, что все зависимости установлены

**Q: Claude Desktop не видит сервер**
A: Проверьте правильность пути в конфигурации Claude Desktop
